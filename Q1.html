Inventer of The Web: Tim Berners Lee

The man, the myth, the legend, Tim Berners Lee. Born in 1955, Tim followed a career as a computer scientist and software engineer. Throughout this career, he accomplished many historically significant goals that contributed to the World Wide Web we know today. In 1982, Tim proposed a global hypertext system that would let researchers share documents. Then, in 1990-1991, he developed the first web browser along with the first web server. He also created the early HTML language, the same language we use in this course. He did this and more while working for CERN (European Organization for Nuclear Research).
